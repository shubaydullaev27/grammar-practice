Should have / shouldn't have

We use should have + past participle (V3) to talk about something that was a good idea, but did not happen.

  • should have + V3 → the person did not do something they needed to do.
    I should have studied more. (= I didn't study enough.)

We use shouldn't have + V3 to talk about something that was a bad idea and happened.

  • shouldn't have + V3 → the person did something they should not have done.
    I shouldn't have stayed up so late. (= I stayed up too late.)
Form: should have + V3  ·  shouldn't have + V3
