1. The main idea

We use the first conditional to talk about a real, possible situation in the future and its result.

If + present simplethe condition
,
will / won’t / might + verbthe result (no to)
If it rains tomorrow, we will stay at home.
Tomorrow = future, but the verb after if is in the present simple.

2. Form

If + present simplewill / won’t / might + verb
+ PositiveIf Pablo comes here,he will bring his family.
– NegativeIf you don’t visit Lin,she won’t be happy.
Not sureIf I meet the Director,I might discuss my pay.
? QuestionIf I don’t stay for dinner,will they be upset?
Remember
  • After if we use the present simple, not will: If it rains, …  If it will rain, …
  • He / she / it → add -s in the if clause: If she calls, …  Negative: If he doesn’t come, …
  • After will / won’t / might use the base verb (no to): we will stay  we will to stay

3. Which clause comes first?

If clause first → comma ( , ) If I meet Cathy, I’ll invite her for dinner.
If clause second → no comma I’ll invite Cathy for dinner if I meet her.

The meaning is the same. Only the order changes.

4. will, won’t or might?

won’tsure: NO
might notmaybe NO
mightmaybe YES
willsure: YES
  • will / won’t → the result is certain: If you don’t thank them, they won’t invite us again.
  • might / might not → the result is not certain: If you speak too fast, they might not understand you.
  • You can use other modals too: can, may, could, should. If it’s sunny, we can swim. In the exercises, any logical modal is accepted.
