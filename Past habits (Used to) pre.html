1. The main idea

We use used to for regular actions and situations that were true in the past but are not true now.

in the pasttrue then ✔
used to send telegramsregular action
NOW ✘
People used to send telegrams. (They don’t send them now.)
I used to be very shy, but now I’m more confident.

2. Form

FormExample
+ Positivesubject + used to + base verbWe used to swim in the sea.
– Negativesubject + didn’t use to + base verbWe didn’t use to have a TV.
? QuestionDid + subject + use to + base verb?Did you use to watch videos at school?
Remember
  • used to is the same for all subjects (I, he, they used to).
  • After did / didn’t we write use to (no -d): I didn’t use to like it.  I didn’t used to like it.
  • After used to use the base verb: used to play  used to playing
  • Short and full forms are both correct: didn’t = did not.

3. Positive, negative or question? Key words

used to

Positive: a past habit or state
Clue words
when I was a childyears agoevery summerbefore we had a TVbut now …
My brother used to play football every weekend, but now he doesn’t have time.

didn’t use to

Negative: it wasn’t true then
Clue words
(not …) in bracketsbut now she loves itbut now he likes it
She didn’t use to enjoy reading, but now she loves books.
Questions Two gaps: write Did in the first gap and use to + verb in the second gap.
Did your family use to travel a lot when you were a child?

4. When we DON’T use used to

An action that happened once ✔ I wrote a news article once.
✘ I used to write a news article once.
A number of times or a period of time ✔ I was on TV five times.
✘ I used to be on TV five times.
Not for the present ✔ I usually get my news online these days.
✘ I used to get my news online these days.

5. Comparing past and present

News programmes used to be more boring than they are now.
We use used to with states (be, have, like, live) and habits (play, go, eat, watch).

6. Quick check

  1. Was it true in the past but not now? → use used to.
  2. See (not …)? → didn’t use to + verb.
  3. Is it a question? → Did + subject + use to + verb?
