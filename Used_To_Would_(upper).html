Grammar Guide

Four patterns look similar but mean different things. Each one has its own colour in this guide and in the exercises, so you can see at a glance which pattern you are practising.

1
used to + infinitive
Past habits and states
Formsubject + used to + base verb Meaning

Something that was true, or happened regularly, in the past but is not true now.

Examples

I used to play the violin.

There used to be a cinema here.

Negative and question

didn't use to + verb  ·  Did … use to + verb? (no -d)

Watch out: past only. There is no present form (✗ I use to play).
2
would + infinitive
Repeated past actions
Formsubject + would + base verb Meaning

Actions that were repeated in the past. The past time must already be clear (when I was a child, every summer, in those days).

Examples

Every summer we would swim in the lake.

Our grandmother would always bring us sweets.

Watch out: actions only, never states. ✗ I would have long hair → ✓ I used to have long hair.
3
be used to + -ing
Accustomed, familiar
Formsubject + be (am / is / are / was / were) + used to + -ing or noun Meaning

You know something well, so it is not strange or difficult for you.

Examples

I am used to getting up early.

She wasn't used to the cold.

Time

Any time: am used to (now), was used to (then), will be used to (future).

Watch out: after to comes -ing or a noun, not the base verb (✗ I'm used to live here).
4
get used to + -ing
Becoming accustomed
Formsubject + get (get / gets / got / getting) + used to + -ing or noun Meaning

The process of becoming familiar with something new. It takes time.

Examples

I'm getting used to living alone.

It took me a month to get used to the noise.

Time

Any tense: is getting (now), got (past), will get (future), can't get.

Watch out: same rule as be used to: -ing or a noun comes after to.

Which one should I use?

  1. 1
    Is the sentence about the past only, and not true now? Is the next word a base verb (live, play, be)? → used to. For a repeated action with a clear past time, would is also possible.
  2. 2
    Does the person already know it well, so it feels normal? Look for for years, already, all his life. → be used to + -ing.
  3. 3
    Is the person becoming familiar, or did it happen over time? Look for gradually, at first, soon, it took me. → get used to + -ing.
Quick test: if you can say accustomed to, use be / get used to + -ing. If the sentence only describes a finished past habit or state, use used to + infinitive.

Common mistakes

I use to play tennis.
I used to play tennis.
She didn't used to smoke.
She didn't use to smoke.
We would live in a small flat.
We used to live in a small flat.
I'm used to live alone.
I'm used to living alone.
He used to working hard.
He used to work hard. / He is used to working hard.
I'm getting used to wake up early.
I'm getting used to waking up early.
