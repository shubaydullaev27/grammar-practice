1. The main idea

We use the second conditional for unlikely or imaginary situations and their results.

If + past simplethe imaginary condition
,
would / wouldn’t + verbthe result (no to)
If we found a cure for malaria, millions of lives would be saved.
We don’t have a cure now. We imagine it.

2. Real or imaginary?

First conditional

Real, possible
If it rains, we will stay at home.
If + present → will

Second conditional

Unlikely, imaginary
If I won the lottery, I would buy a house.
If + past → would

3. Form

If + past simplewould / wouldn’t + verb
+ PositiveIf we used solar power,we would save money.
– NegativeIf people didn’t drive,the air would be cleaner.
If my country was richer, I wouldn’t want to live abroad.
? QuestionIf we used solar power,would we save money?
What would you do if you won a prize?
Remember
  • would / wouldn’t is the same for all subjects: I would, he would, they would. Short form: I’d, we’d.
  • After if use the past simple, not would: If I had money, …  If I would have money, …
  • The past tense here is not about the past. It shows the situation is imaginary.
  • After would use the base verb: I would go  I would to go

4. would, could or might?

would

The usual result
If I won, I would buy a house.

could / might

could = able, possible  |  might = maybe
If I had a car, I could drive to work.
If I won, I might buy an island.

In the exercises, would, could or might (and their negatives) are all accepted.

5. The verb be: was or were?

I / he / she / it was or were are both correct:
If he was / were taller, he would play football.
If I were you, … For advice we use were:
If I were you, I would accept the offer.

You / we / they → always were: If we weren’t so busy, …

6. Which clause comes first?

If clause first → comma ( , ) If she created more jobs, she would be popular.
If clause second → no comma She would be popular if she created more jobs.

8. Quick check

  1. Is the situation imaginary or unlikely? → second conditional.
  2. If clause: past simple (for be: were / was; negative: didn’t).
  3. Result: would / wouldn’t (or could, might) + base verb. Question: Would you …?
